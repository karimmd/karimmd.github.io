# Md Monjurul Karim — Portfolio

This repository is prepared as a simple static GitHub Pages site.

## Local preview

```bash
python3 -m http.server 1316
# open http://127.0.0.1:1316/
```

## Publish to GitHub Pages

For the user site repository `karimmd.github.io`, GitHub Pages serves the repository root from the `main` branch.

```bash
git add -A
git commit -m "Replace Hugo site with minimalist static portfolio"
git push origin main
```

Then open: https://karimmd.github.io/
