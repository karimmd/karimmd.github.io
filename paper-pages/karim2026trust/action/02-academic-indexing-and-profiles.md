# Agent Task 02: Check Academic Indexing and Profile Visibility

## Goal

Ensure the paper is discoverable across academic search engines, author profiles, institutional pages, and bibliographic databases. The task is to verify visibility and consistency, not to invent missing information.

## Paper metadata

Title: From trust to augmentation: A comprehensive survey on synergistic integration of decentralized and generative intelligence

Authors: Md Monjurul Karim; Sangeen Khan; Qiang Qu; Muhammad Muzammal; Kashif Sharif; Sujit Biswas

Journal: Computer Science Review

Volume: 61

Article: 100936

Year: 2026

DOI: <https://doi.org/10.1016/j.cosrev.2026.100936>

Project page: <https://karimmd.github.io/paper-pages/karim2026trust/>

## Sources to check

Check the following sources and record the URL/status for each:

1. Google Scholar
2. Semantic Scholar
3. OpenAlex
4. Crossref
5. Scopus, if accessible
6. Web of Science, if accessible
7. DBLP
8. ORCID pages for all authors, if public
9. ResearchGate
10. ScienceDirect
11. Northumbria Research Portal
12. City Research Online
13. SIAT/CAS or UCAS profile pages, if available
14. Beijing Institute of Technology profile page for Kashif Sharif, if available
15. Karim's website main publication list: <https://karimmd.github.io/>

## What to verify

For each source, check:

- Is the paper present?
- Is the title correct?
- Are all authors listed in the correct order?
- Is the DOI correct?
- Is the journal/volume/article number correct?
- Does it link to the DOI, ScienceDirect, or project page?
- Does it show citations? If yes, record the citation count and date checked.

## Output format

Create a table like this:

| Source | Present? | URL | Metadata correct? | Citation count | Issues | Recommended action |
|---|---:|---|---:|---:|---|---|
| Google Scholar | Yes/No | URL | Yes/No | N/A or number | ... | ... |

## Important rules

- Do not guess citation counts.
- If a source requires login and access is unavailable, write `Access unavailable`.
- If a profile is not found, write `Not found after checking: [queries used]`.
- Do not edit external profiles unless Karim explicitly provides access and approval.

## Recommended improvements to identify

Look for opportunities such as:

- Add project page link to author profile.
- Add DOI to institutional repository entry.
- Add accepted manuscript if allowed by publisher policy.
- Add ORCID works entry if missing.
- Correct metadata inconsistency.

## Deliverable

Return:

1. Completed indexing/profile table.
2. List of profile/database issues.
3. Suggested corrections Karim or coauthors should make manually.
4. Any source requiring login or manual access.
